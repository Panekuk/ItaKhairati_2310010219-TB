# 📌 Sistem Kepegawaian

Aplikasi **Sistem Kepegawaian** berbasis **Java Desktop (Swing + JDBC)**  
Digunakan untuk mengelola data pegawai, absensi, cuti, serta laporan kepegawaian.

---

## 🚀 Fitur Utama
- Login pengguna
- Menu utama aplikasi
- Manajemen data pegawai (CRUD)
- Absensi pegawai (cegah absen dobel & hitung keterlambatan)
- Pengajuan & pengelolaan cuti
- Laporan absensi & cuti (PDF)

---

## 🛠 Teknologi
- Java SE (Swing)
- JDBC (MySQL)
- NetBeans IDE
- MySQL Database

## ⚙️ Cara Menjalankan
1. Import project ke **NetBeans**
2. Pastikan database MySQL sudah dibuat
3. Atur koneksi database di `Koneksi.java`
4. Jalankan aplikasi melalui `MenuUtama.java`

---

## 📌 Catatan
- Aplikasi menggunakan **Java 8 / Java 11**
- Tidak menggunakan Java Text Block (`"""`)
- Cocok untuk tugas akhir / proyek sistem informasi
